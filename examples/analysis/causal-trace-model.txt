Causal trace model

Vertices: events E, messages M, sequential execution contexts X, nodes N. Events have unique IDs/timestamps and belong to one context; contexts run on one node. Messages have one logical sender and zero or more receivers. Global traces unite through shared message identities.

Typed relations (parallel types can connect the same vertices; map roles to the schema):
- by: e -> f, semantic causation on one node, including asynchronous initiation/completion.
- nx: e -> f, immediate successor within one context; a context's events form a chain.
- snd: send event -> message.
- rcv: receive event -> message.
- in: event -> context.
- on: context -> node.

Causal order is reachability by nonempty paths in the acyclic event projection H=(E, by union nx union dlv). Derive dlv by joining snd/rcv through message identity: send -> receive. Raw send -> message <- receive is NOT a directed event-to-event path. Flattened inputs may already contain dlv. Include nx unless explicitly narrowing the query. Hierarchy provides context, never causal paths.

Between(s,t) is the induced event subgraph containing both endpoints and every event reachable from s that can reach t. Retain all branches, not one witness path. State whether output is an event projection or full typed trace.

Correlate logical participants/messages; do not require identical endpoint contexts or choose by nearest timestamp. One matched pair contributes one endpoint-time difference, regardless of route count. Establish units and clock comparability. Unobserved boundaries mean incomplete evidence: missing paths do not prove concurrency, completion or deadlock.
